# 3rdGenericBase
Simple base for a 3rd person game with physics-based movement.

### Controls 
```
WASD: Movement  
Space: Jump  
Right Click: Aim (Hold)  
Left Click: Charge shot (Hold and release)  
```

A base for starting a 3rd person game using a rigidbody based player that hovers over the ground, so it can go up small ledges and climb over slopes with simple logic and can be combined with Inverse Kinematics in the character limbs for more realism.  
Also includes an 3rd person aiming system which checks for walls or obstacles in the reticle to correct the aiming.
